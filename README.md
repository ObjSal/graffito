# graffito — moved

This repository is a redirect stub. Graffito now lives at
**[github.com/ByteApps/graffito](https://github.com/ByteApps/graffito)**,
and its web pages at **https://byteapps.github.io/graffito/**.

The stub exists because GitHub Pages URLs do **not** redirect when a
repository is transferred, and `objsal.github.io/graffito/...` is baked into
shipped app builds and into note QR codes already in the wild. Every page
here forwards to the same path on the new host, preserving the query string
and fragment (which is where a note's address and id live). `404.html`
catches anything not enumerated.

Do not add content here. Open issues and pull requests on the real repo.
